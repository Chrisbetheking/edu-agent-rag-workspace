# 面试讲解提纲

## 1. 项目背景

我之前做过一个纯前端 AI 留学申请工作流 Demo，主要验证 CGPA 换算、院校推荐和申请文案生成等业务流程。后来发现纯规则 Demo 在语义检索、来源追溯、多轮对话和工程化方面不足，所以我把它重构成了 EduAgent：AI Agent + RAG 留学咨询工作台。

## 2. 核心功能

- 知识库上传和文档切片
- RAG 检索问答和来源引用
- CGPA 换算、院校推荐、销售话术生成等 Agent 工具
- Prompt 模板管理
- 工具调用日志
- RAG 评测面板
- SSE 流式输出

## 3. RAG 怎么做

链路是：文档上传 → 文本解析 → chunk 切片 → query 检索 → Top-K 召回 → 拼接上下文 → 生成回答 → 返回来源引用。

当前版本为了演示和控制成本，使用 Mock embedding 和简单相似度检索。后续可以替换为真实 embedding API 和 pgvector。

## 4. Agent 工具怎么做

我把业务能力封装成工具函数，例如 CGPA 换算、院校推荐、话术生成。每个工具都有固定输入参数、输出结构、调用日志和失败兜底。这样比单纯聊天更像真实业务系统。

## 5. 如何控制 API 成本

- API Key 只放后端环境变量
- 前端不直接调用模型接口
- Demo 模式默认用 Mock 结果
- 加登录和请求次数限制
- 限制输入长度和输出长度
- 公开演示时可以关闭真实模型调用
